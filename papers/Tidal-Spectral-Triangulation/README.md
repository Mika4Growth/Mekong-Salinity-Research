## Overview of the project
**This project** applies a four-stage spectral triangulation protocol to a sixteen-year record of daily maximum salinity from the Tien River estuary. It challenges the common practice of selecting lookback windows for salinity forecasting through empirical grid search, demonstrating that the frequently selected fortnightly window corresponds to a precise, identifiable triplet of physical periodicities.

* **Domain:** Time series analysis · Spectral estimation · Seasonality
diagnostics · Tidal aliasing.
